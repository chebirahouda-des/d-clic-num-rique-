Découvrir la cybersécurité

Apprends à protéger tes appareils, tes comptes et tes données personnelles.

1. Comprendre la cybersécurité

La cybersécurité consiste à protéger les ordinateurs, les téléphones, les comptes et les informations personnelles contre les dangers informatiques.

Pourquoi est-elle importante ?

Elle permet d'éviter le vol de données, les piratages et les arnaques sur Internet.

Les principaux dangers

  • Les virus informatiques
  • Le piratage des comptes
  • Les faux messages et les arnaques
  • Le vol des informations personnelles

2. Créer un mot de passe sécurisé

Un mot de passe permet de protéger l'accès à un compte ou à un appareil.

Les règles à respecter

  • Utiliser au moins 12 caractères.
  • Mélanger les lettres, les chiffres et les symboles.
  • Éviter les informations personnelles.
  • Ne jamais partager son mot de passe.
  • Utiliser un mot de passe différent pour chaque compte.

3. Reconnaître les arnaques sur Internet

Les cybercriminels utilisent parfois de faux messages pour voler des informations personnelles.

Comment reconnaître un message suspect ?

  • Un expéditeur inconnu.
  • Des fautes d'orthographe inhabituelles.
  • Un lien étrange ou inconnu.
  • Une demande urgente de mot de passe ou d'argent.

Que faire ?

Ne clique pas sur les liens suspects et ne communique jamais tes informations personnelles. En cas de doute, vérifie directement auprès de l'organisme concerné.

4. Protéger ses données personnelles

Les données personnelles sont les informations qui permettent de nous identifier, comme notre nom, notre adresse ou notre numéro de téléphone.

Les bons réflexes

  • Éviter de publier des informations privées sur les réseaux sociaux.
  • Vérifier les paramètres de confidentialité.
  • Faire les mises à jour de ses appareils.
  • Éviter les réseaux Wi-Fi publics pour les opérations sensibles.
  • Ne pas télécharger des fichiers provenant de sources inconnues.
